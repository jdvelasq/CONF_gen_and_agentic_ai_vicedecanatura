2025 · Skills: procedimientos reutilizables

Una skill convierte el saber hacer de un equipo en un procedimiento que el agente puede cargar cuando lo necesita.

  • Skill (octubre): carpeta con instrucciones y recursos que el agente usa bajo demanda.
  • Prompt: una petición concreta.
  • Skill: cómo se hace un tipo de tarea.
  • Conector: acceso a un sistema.
  • Revisa las skills de terceros antes de instalarlas: pueden no estar auditadas.

Ejemplo: una skill «informe mensual» guarda la plantilla, el tono y las cifras obligatorias; tú solo pides «prepara el informe de octubre».
