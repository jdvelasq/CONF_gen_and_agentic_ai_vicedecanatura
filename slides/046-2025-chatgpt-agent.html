2025: de Operator a ChatGPT Agent

Investigar y actuar se reúnen en un mismo flujo conversacional.

  • Operator (enero): opera sitios web con capturas, clics y escritura.
  • ChatGPT Agent (julio): reúne investigación, navegación y acciones.
  • Las acciones requieren controles y supervisión.
  • La autonomía no garantiza éxito.
