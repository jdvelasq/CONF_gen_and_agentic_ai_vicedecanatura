Octubre de 2024: usar el computador como una persona

El modelo ya puede ver una pantalla y actuar sobre ella, sin necesitar una conexión específica con cada programa.

  • Computer use: el modelo observa capturas y usa clics y teclado.
  • Browser use: la misma idea, aplicada al navegador.
  • Sirve donde no existe una integración directa.
  • Depende de interfaces que cambian.
