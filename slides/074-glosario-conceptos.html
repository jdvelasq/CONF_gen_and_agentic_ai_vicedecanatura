Glosario: cómo funciona

Este vocabulario permite entender qué ocurre dentro de un asistente.

Token
Fragmento de texto que el modelo procesa como unidad.
Contexto
Información que el modelo recibe en una petición.
Ventana de contexto
Máximo de tokens que puede considerar.
Parámetros
Valores internos ajustados al entrenar.
Pesos
Los parámetros entrenados del modelo.
Entrenamiento
Etapa en la que el modelo aprende.
Inferencia
Etapa en la que el modelo se usa.
Embedding
Representación numérica del significado.
RAG
Buscar evidencia y entregarla al modelo antes de responder.
Alucinación
Respuesta falsa presentada como cierta.
Modelo de frontera
Modelo de mayor capacidad en su momento.
Modelo de razonamiento
Usa más cómputo antes de responder.
Multimodalidad
Trabajar con varios tipos de información.
Modelo abierto
Sus pesos se pueden descargar.
Modelo local
Se ejecuta en el equipo del usuario.
Nube
Se ejecuta en servidores del proveedor.
