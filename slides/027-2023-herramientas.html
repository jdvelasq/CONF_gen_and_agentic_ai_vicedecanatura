2023 · Herramientas y GPTs: el modelo gana manos

Con las herramientas, el modelo deja de limitarse a hablar y puede pedir que algo se haga; los productos cambian, tus procedimientos continúan.

  • Function calling (junio): el modelo solicita una acción de forma estructurada.
  • Herramienta (tool): función externa que el modelo puede solicitar, como buscar o calcular.
  • El modelo la solicita; el sistema la ejecuta y devuelve el resultado.
  • GPTs (noviembre): asistentes configurados una vez para un propósito y reutilizables.
  • Plugins retirados en abril de 2024; Assistants API, en agosto de 2026.
  • Práctica: conserva tus prompts y procedimientos fuera de la herramienta.
