2025 · Agentes de código: el patrón nace entre programadores

La programación impulsó la delegación a agentes; ese mismo ciclo también se aplica hoy a tareas de oficina.

  • Claude Code (febrero) y Codex (abril-mayo) reciben objetivos y trabajan por etapas.
  • Claude 4 (mayo) se orienta a tareas prolongadas con herramientas.
  • El usuario ya no observa cada paso: revisa el resultado.
  • Este patrón se traslada luego a Cowork y ChatGPT Work.

Ejemplo: «Corrige este error y ejecuta las pruebas»: el agente edita, prueba y entrega los cambios para revisión.
