2025 · Vibe coding: crear software describiendo lo que quieres

Sin ser programador se puede convertir una idea en una herramienta, siempre que se reconozcan sus límites.

  • Vibe coding (febrero): crear software describiendo lo deseado en lenguaje natural.
  • Útil para prototipos, automatizaciones personales y herramientas internas.
  • No equivale a ingeniería de software.
  • Antes de usarlo con datos reales, pide una revisión técnica.

Ejemplo: describes «una página para registrar las solicitudes del equipo» y obtienes un prototipo. Antes de guardar datos reales, lo revisa alguien técnico.
