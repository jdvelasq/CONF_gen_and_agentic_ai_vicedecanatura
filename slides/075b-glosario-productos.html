Glosario: modelos, productos y datos

Este vocabulario permite comparar opciones y proteger la información.

API
Canal para que otros programas usen un modelo.
LLM
Modelo de lenguaje de gran tamaño.
Modelo de frontera
Modelo de mayor capacidad en su momento.
Modelo open-weight
Modelo cuyo archivo se puede descargar; su licencia puede restringir el uso.
Cuantización
Guardar los pesos con menos precisión para que ocupen menos memoria.
GPU
Chip especializado en cálculos de IA.
Latencia
Tiempo de espera hasta recibir la respuesta.
Copiloto
Asistente que propone; no ejecuta objetivos por sí solo.
Memoria
Lo que sobrevive de una conversación a otra.
Proyecto
Espacio con instrucciones y archivos fijos para un mismo trabajo.
Artefacto
Resultado independiente que se revisa y se ajusta.
Búsqueda semántica
Encuentra textos de significado parecido.
Agente persistente
Sigue activo entre sesiones.
Vibe coding
Crear software describiendo lo deseado en lenguaje natural.
Entrenamiento con datos
Uso de tus contenidos para mejorar modelos futuros.
Anonimizar
Retirar lo que identifique a personas o clientes.
