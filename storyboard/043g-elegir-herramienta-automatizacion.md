# Título

Herramientas: elegir sin programar

# Mensaje clave

Empieza por las conexiones y los permisos disponibles.

# Competencia

No existe una herramienta universal: importan las aplicaciones que ya utiliza la organización.

# Visual

Secuencia lineal editable de 4 pasos con paleta Tableau, encabezado oscuro y una idea central.

1. **Power Automate:** Si el trabajo ocurre en Microsoft 365.
2. **Workspace Studio:** Si la organización usa Google Workspace y tiene acceso.
3. **Zapier o Make:** Para conectar servicios mediante flujos visuales.
4. **n8n:** Para procesos configurables y posible alojamiento propio.

# Cierre y criterio de aprendizaje

Comprueba licencias, integraciones, políticas de datos y soporte antes de elegir.
