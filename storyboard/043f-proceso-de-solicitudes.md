# Título

Un proceso universitario sin programar

# Mensaje clave

Separa decisiones del modelo y reglas de la institución.

# Competencia

Ejemplo: organizar solicitudes administrativas recibidas mediante un formulario autorizado.

# Visual

Secuencia lineal editable de 5 pasos con paleta Tableau, encabezado oscuro y una idea central.

1. **Recibir:** El formulario inicia el flujo.
2. **Verificar:** Comprueba campos y duplicados.
3. **Clasificar:** La IA sugiere el tema.
4. **Asignar:** Una regla elige responsable.
5. **Aprobar:** Una persona valida la respuesta.

# Cierre y criterio de aprendizaje

Si faltan datos, el proceso se detiene y pide revisión; no inventa información.

# Ubicación

Después de la introducción a workflows y procesos automáticos (043c), antes de DeepSeek (044). Destinatarios: profesionales sin conocimientos de programación.
