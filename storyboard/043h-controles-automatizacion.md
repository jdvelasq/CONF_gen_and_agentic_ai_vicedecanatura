# Título

Automatizar con control

# Mensaje clave

La IA propone; el sistema controla.

# Competencia

Una automatización útil debe detenerse, explicarse y recuperarse cuando algo falla.

# Visual

Secuencia lineal editable de 4 pasos con paleta Tableau, encabezado oscuro y una idea central.

1. **Antes:** Datos autorizados y permisos mínimos.
2. **Durante:** Reglas, comprobaciones y registro de acciones.
3. **Al decidir:** Aprobación humana de envíos o cambios sensibles.
4. **Si falla:** Alerta, revisión y protección frente a duplicados.

# Cierre y criterio de aprendizaje

Nunca publiques, pagues, borres ni envíes información sensible sin autorización.

# Ubicación

Después de la introducción a workflows y procesos automáticos (043c), antes de DeepSeek (044). Destinatarios: profesionales sin conocimientos de programación.
