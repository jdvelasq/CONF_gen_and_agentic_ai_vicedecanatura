# Título

Enero de 2026: Claude Cowork

# Mensaje clave

Cowork lleva a las tareas de oficina el bucle de agente que antes exigía Claude Code.

# Contenido en pantalla

- El usuario da un objetivo.
- Claude trabaja sobre archivos y herramientas.
- Devuelve un resultado para revisión.
- Tareas: analizar, redactar y organizar.
- Dispatch (marzo): delegar desde el móvil al computador.

# Visual sugerido

Flujo: objetivo, carpeta de archivos, plan visible, entregable y revisión humana.
