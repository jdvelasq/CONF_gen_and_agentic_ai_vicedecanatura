# Título

No todo necesita un agente

# Mensaje clave

Primero se define el problema; la autonomía se añade solo si aporta valor.

# Contenido en pantalla

- Flujo de trabajo (workflow): pasos definidos de antemano.
- Agente: decide los pasos a medida que avanza.
- A más autonomía, mayor necesidad de supervisión.
- No empiece preguntando "¿qué agente puedo construir?".

# Visual sugerido

Escala de autonomía: prompt, flujo de trabajo, agente supervisado, agente persistente.
