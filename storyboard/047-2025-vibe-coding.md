# Título

Febrero de 2025: vibe coding

# Mensaje clave

Sin ser programador se puede convertir una idea en una herramienta, siempre que se reconozcan sus límites.

# Contenido en pantalla

- Vibe coding: crear software describiendo lo deseado en lenguaje natural.
- Útil para prototipos, automatizaciones personales y herramientas internas.
- No equivale a ingeniería de software.
- Antes de usarlo con datos reales, pida una revisión técnica.

# Visual sugerido

Secuencia de idea a prototipo, con una barrera marcada antes de "uso con datos reales".
