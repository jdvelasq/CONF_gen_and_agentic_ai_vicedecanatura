Cuatro palabras para empezar

# Mensaje clave

Estas cuatro definiciones ordenan todo el recorrido.

# Contenido en pantalla

- Inteligencia artificial: sistemas que realizan tareas asociadas con la inteligencia humana.
- Modelo: programa entrenado con datos para reconocer patrones y producir resultados.
- IA generativa: modelos que crean contenido nuevo, como texto, imagen, audio o video.
- IA agéntica: sistemas que usan modelos y herramientas para alcanzar un objetivo en varios pasos.

# Visual sugerido

Círculos concéntricos: inteligencia artificial, IA generativa e IA agéntica, con el modelo como pieza común.
