# Título

Anatomía de un prompt estructurado

# Mensaje clave

Una buena instrucción es un encargo claro, como el que se daría a un colega nuevo.

# Contenido en pantalla

- Rol: desde qué experiencia responder.
- Contexto: situación y audiencia.
- Tarea: qué hacer, con un verbo de acción.
- Datos de entrada: material con el que trabajar.
- Restricciones: límites, tono y qué evitar.
- Ejemplos: muestras del resultado esperado.
- Formato de salida: estructura de la entrega.
- Criterios de calidad: cómo juzgar el resultado.

# Visual sugerido

Un prompt real de un caso administrativo, con cada parte resaltada en un color y su nombre al margen.
