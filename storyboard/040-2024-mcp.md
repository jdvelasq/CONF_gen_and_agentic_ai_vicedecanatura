# Título

Noviembre de 2024: MCP, el conector universal

# Mensaje clave

MCP estandariza cómo se conectan los asistentes con otras aplicaciones y datos.

# Contenido en pantalla

- MCP (Model Context Protocol): estándar abierto para conectar la IA con herramientas y datos.
- Conector: la conexión que aparece en el asistente, por ejemplo con Google Drive.
- Antes: una integración distinta para cada combinación.
- Pregunta clave: ¿dónde quedan datos y credenciales?
