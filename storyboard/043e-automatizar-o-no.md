# Título

¿Qué tareas conviene automatizar?

# Mensaje clave

Un buen candidato tiene límites claros.

# Competencia

Antes de elegir una herramienta, identifica una tarea frecuente, estable y con resultados verificables.

# Visual

Secuencia lineal editable de 4 pasos con paleta Tableau, encabezado oscuro y una idea central.

1. **Alta repetición:** Ocurre cada semana o cada mes.
2. **Entrada definida:** Se sabe qué información recibe.
3. **Reglas explícitas:** Se sabe qué hacer en casos habituales.
4. **Resultado comprobable:** Una persona puede revisar si funcionó.

# Cierre y criterio de aprendizaje

No automatices decisiones sensibles o excepcionales sin revisión y autorización.
