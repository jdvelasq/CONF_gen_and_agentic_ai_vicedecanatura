# Título

2023: las herramientas, primeras manos del modelo

# Mensaje clave

Con las herramientas, el modelo deja de limitarse a hablar y puede pedir que algo se haga.

# Contenido en pantalla

- Plugins de ChatGPT (marzo): conectan la conversación con servicios externos.
- Function calling (junio): el modelo solicita una acción de forma estructurada.
- Herramienta (tool): función externa que el modelo puede solicitar, como buscar o calcular.
- El modelo la solicita; el sistema la ejecuta y devuelve el resultado.

Diálogo de cuatro pasos entre modelo y calculadora: petición, solicitud, resultado y respuesta.
