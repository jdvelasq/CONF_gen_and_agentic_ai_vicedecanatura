# Título

Octubre de 2025: skills, procedimientos reutilizables

# Mensaje clave

Una skill convierte el saber hacer de un equipo en un procedimiento que el agente puede cargar cuando lo necesita.

# Contenido en pantalla

- Skill: carpeta con instrucciones y recursos que el agente usa bajo demanda.
- Prompt: una petición concreta.
- Skill: cómo se hace un tipo de tarea.
- Conector: acceso a un sistema.
- Revise las skills de terceros antes de instalarlas: pueden no estar auditadas.

# Visual sugerido

Una persona nueva en una oficina: el prompt es el encargo, la skill es el manual y el conector es la llave.
