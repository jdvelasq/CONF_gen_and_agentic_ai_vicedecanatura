# Título

Errores: revisar un entregable

# Mensaje clave

Una lista corta de revisión convierte la supervisión en un hábito.

# Contenido en pantalla

- ¿Cumple lo que se pidió?
- ¿Coinciden cifras y fórmulas con la fuente?
- ¿Existen las referencias citadas?
- ¿Qué cambió en los archivos?
- ¿Firmaría usted este resultado?

# Visual sugerido

Lista de verificación sobre un entregable, con la última pregunta destacada.
