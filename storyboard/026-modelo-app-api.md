# Título

Tres cosas que se confunden

# Mensaje clave

Un mismo nombre puede referirse a cosas distintas; separarlas ayuda a entender qué se contrata.

# Contenido en pantalla

- Modelo: el motor que genera, por ejemplo GPT-4.
- Aplicación: el producto que se usa, por ejemplo ChatGPT.
- API: vía para que otros programas usen el modelo.
- Cambiar de aplicación no siempre significa cambiar de modelo.

# Visual sugerido

Tres capas apiladas: motor, API y aplicaciones, con varias aplicaciones sobre un mismo motor.
